# personal-site

Terminal-style personal portfolio built with Next.js 16, React 19, Tailwind CSS v4, and Framer Motion. Near-black with a green accent; single content column with a file-tree sidebar, and an interactive terminal overlay (press `` ` ``) that mirrors the page content — games included.

## Development

Use Node.js 24 LTS (also used in CI) and npm. No environment variables are required.

```bash
npm ci
npm run dev
```

## Scripts

- `npm run dev`: start the local dev server at `http://localhost:3000`
- `npm run build`: create the production build
- `npm run start`: serve the production build locally
- `npm run lint`: run ESLint
- `npm run typecheck`: generate route types and check TypeScript without emitting files

## Verification

Pull requests and pushes run a locked dependency install, ESLint, TypeScript, a dependency audit, and a production build in GitHub Actions. Run the same checks locally before review:

```bash
npm run lint
npm run typecheck
npm audit --audit-level=moderate
npm run build
npm run start
```

Smoke-test the production server on desktop and mobile, including keyboard navigation, the terminal and games, résumé downloads, and external links. Check reduced-motion and JavaScript-disabled rendering after changing animations. The build downloads the Google Fonts used by `next/font` and requires network access; fonts are then served by the app.

## Project Structure

- `app/`: App Router entry points, layout, and global CSS
- `components/`: reusable UI and terminal game components
- `sections/`: page-level content blocks
- `lib/`: typed content and terminal command helpers
- `public/`: static assets (including `Rafeed_Iqbal_Resume.pdf`, the downloadable résumé)

The current résumé source is `Resume/Rafeed_Iqbal_Resume_2026.pdf`; the published copy is byte-identical at `public/Rafeed_Iqbal_Resume.pdf`. Older source files remain in `Resume/` for reference.

## Content and metadata

`lib/content.ts` is the shared source for page content, terminal commands, and profile metadata. `PROFILE.siteUrl` uses the canonical `https://www.rafeed.dev` origin, matching the hosting redirect. The sitemap omits `lastModified` until a real content-update date can be supplied. Social cards and icons are generated by the metadata routes in `app/`.

The downloadable résumé is a separate PDF. When changing roles, dates, or projects, update the source résumé and replace `public/Rafeed_Iqbal_Resume.pdf` together after confirming the facts.

Security response headers are configured in `next.config.ts`. Hosting should serve HTTPS and preserve those headers. The policy prevents framing and plugin embeds; it deliberately does not restrict inline scripts/styles required by static Next.js rendering and animations.
